# 🚀 University Platform

Welcome! This is a simple PHP university management system built to help students, teachers, and admins manage academic work in one place.

## ✨ What you get

- ✅ Login and role-based access
- 📚 Subject and resource management
- 🧑‍🎓 Student dashboard and academic tracking
- 👩‍🏫 Teacher upload and content control
- 🧠 Quiz and result monitoring
- 📁 Profile and syllabus upload support
- 🤖 Smart AI-based features for a modern experience

## 🧩 Project layout

- `index.php` — main app entry
- `config.php` — application configuration
- `includes/` — shared PHP logic
- `modules/` — admin, student, and teacher pages
- `assets/` — CSS and JavaScript
- `uploads/` — user-uploaded files

## 🛠️ What you need

- PHP
- MySQL or MariaDB
- XAMPP, WAMP, or any local PHP server

## 🚀 Run it locally

1. Copy the project into your local web server folder, such as `htdocs` in XAMPP.
2. Set up your database and update the connection settings in `config.php`.
3. Start your local server.
4. Open the app in your browser:

```text
http://localhost/university_platform/
```

## 💡 Helpful reminders
